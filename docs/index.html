Local-First

Built with open technology.

Powered by familiar tools and designed for local execution.

Python Ollama Gemma Markdown Open Source

Your journal, your space.

devReflections uses Ollama to run language models locally. Journal entries are stored on your machine rather than sent to a hosted journaling service.

No external AI API key or cloud account is required for the intended local workflow.

Get started

Explore the source code and run devReflections locally on your machine. 

git clone 
cd devReflections

python -m pip install -e .
python main.py
